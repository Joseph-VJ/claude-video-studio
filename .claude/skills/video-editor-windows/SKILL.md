# Windows video studio

Read E:/Video/CLAUDE.md and the needed stage in E:/Video/plans/CLAUDE-FILE-MAP.md. The former root AGENTS.md was revoked; never import or restore it. Load E:/Video/scripts/env.ps1 before tools. Use PowerShell and existing executables; keep new files, dependencies, models and caches on E:.

For a new video inspect actual content/audio/metadata and make a source-anchored audience/story/cut/colour/motion/sound plan. Never reuse the previous video's grade, white balance, face boxes, LUT or cut boundaries. Continue an existing edit with its own approved settings. Read lasting style/feedback selectively and distinguish them from one-video choices. Use /studio-context and maintain the project's RENDER.md.

Use /video-render-fast and E:/Video/plans/FAST-RENDER-WORKFLOW-v1.md before rendering. Use native FFmpeg or a validated Concat input/effect route for ordinary footage. Use Remotion/HyperFrames for necessary verified custom graphics. This PC's OffthreadVideo crash and HTML5 frame-timing failures are not repaired by replacing ffprobe. Do not force footage through those paths. Reuse installed runtimes; do not run upstream shell installers.

Export a current approved 1080x1920 30 fps SDR master or verified contiguous PNGs with E:/Video/scripts/Export-Instagram.ps1, Encoder nvenc / Quality balanced (default, ~89 MB per 80 s; Quality max only on request). The complete flags/recipes and CPU fallback are in the render guide. Small H.264 MP4 is lossy; preserve the master. FFV1 archival is separate. Use master-delivery.py only for compatible picture-copy/audio-only changes; do not add an extra video encode to master audio.

Custom GPU colour + cuts run through E:/Video/scripts/render-timeline-colour.py (default, cut-first) or render-colour-fast.py (full-length parity/reference), only for an explicit reviewed current-job module/configuration and the HLG input interface. Keep CPU RVM matting by default in the tested configuration. Validate current masks, temporal state, colour and GPU parity. Do not reuse lab job JSON or silently lower matting quality.

Use existing local transcription and explicitly chosen installed models; verify names, numbers and qualifiers from audio. Prior project's Tamil phrase bounds and ASR settings are not new-video defaults. Use /request-video-assets, /image and /video for manually generated assets; inspect returns and preserve provenance.

Keep one cut map, caption track, deliberate colour path and final delivery encode. Reuse only same-job caches with matching identity. Record exact output/version, stage times, technical checks, playback/listening coverage and remaining limits. Do not claim a synthetic smoke test is a creative edit. No paid generation, publication or source upload is implicit.
